# ПЛОЩАДКА. — сайт бронирования конференц-залов

Самостоятельный учебный веб-проект: каталог пространств, регистрация пользователей, бронирование переговорных и конференц-залов, административная панель и отзывы.

## Технологии

- **Node.js 22.13+**, встроенный модуль `node:http` — HTTP-сервер и маршрутизация.
- **SQLite** через встроенный `node:sqlite` (`DatabaseSync`) — хранение данных.
- HTML5, CSS3, JavaScript без библиотек на стороне клиента.
- `node:crypto` (`scrypt`) — безопасное хранение паролей.

Пакетов из npm нет, поэтому проект запускается без `npm install`. База данных создаётся автоматически при первом старте.

## Запуск

```bash
node --version # необходим Node.js >= 22.13
npm start
```

Откройте **http://127.0.0.1:3000**. Чтобы выбрать другой порт: `PORT=8080 npm start` (в Windows PowerShell: `$env:PORT=8080; npm start`). Для автоматического перезапуска при изменениях: `npm run dev`.

## Демо-доступ (только для локального учебного запуска)

| Роль | Логин | Пароль |
| --- | --- | --- |
| Пользователь | `student` | `Student123!` |
| Администратор | `admin` | `Admin2026!` |

При первом запуске пароль администратора можно задать через `DEMO_ADMIN_PASSWORD` — настройка применяется только при первоначальном создании пользователя. **Не публикуйте учебную демо-базу и эти пароли на общедоступном сервере.** При `NODE_ENV=production` обязательна переменная `ADMIN_PASSWORD` (12+ символов), демо-пользователи не создаются. Запускайте production только с новой чистой базой. Для безопасного публичного размещения нужно дополнительно усилить защиту входа и убрать демонстрационные учётные записи.

## Основные страницы

| Страница | Маршрут | Возможности |
| --- | --- | --- |
| Главная | `/` | Приветственный блок, преимущества, подборка залов |
| Каталог | `/rooms` | Фильтрация по категориям |
| Детали зала | `/rooms/:slug` | Параметры зала и отзывы |
| Регистрация / вход | `/register`, `/login` | Создание аккаунта и авторизация |
| Форма бронирования | `/book/:id` | Дата, временной интервал, число гостей |
| Личный кабинет | `/dashboard` | Список и статусы заявок |
| Детали заявки | `/booking/:id` | Информация и отзыв после завершения |
| Панель администратора | `/admin` | Статистика и список заявок |
| Модерация заявки | `/admin/booking/:id` | Подтверждение, отклонение, завершение |

**Бизнес-правила:** время работы 09:00–22:00, минимальный шаг бронирования — один час, нельзя создать заявку на прошедшую дату или больше вместимости, стоимость вычисляется на сервере. Заявки могут быть отправлены на одно время, но администратор не сможет подтвердить конфликтующие; после подтверждения интервал недоступен для новых заявок.

**Оплата:** платёжный шлюз отсутствует — «Оплата на месте» и «По счёту» являются учебными вариантами выбора, без фактического списания средств.

## Защита данных

Пароли хешируются с солью; сессии хранятся в SQLite, сессионный идентификатор — в `HttpOnly` cookie, формы используют CSRF-токены, вывод пользовательских данных экранируется, SQL-запросы параметризованы, права проверяются на сервере.

Это **учебный проект**, не полноценная коммерческая система бронирования. Для публичного запуска дополнительно нужны TLS, ограничения частоты запросов, периодическая очистка базы, резервное копирование, уведомления и боевой механизм оплаты.

## Как выложить проект на GitHub

1. Войдите в GitHub и создайте **пустой** репозиторий `conference-space` (без автоматического создания README/.gitignore).
2. Распакуйте архив, откройте PowerShell в папке проекта и выполните:

   ```powershell
   .\publish-github.ps1 -RepositoryUrl "https://github.com/ВАШ_ЛОГИН/conference-space.git"
   ```

3. При необходимости войдите в GitHub через стандартное окно авторизации Git Credential Manager.

Публикация исходников в репозитории **не запускает** Node.js-сайт как онлайн-сервис. Для работающего сайта требуется отдельный хостинг, поддерживающий Node.js и SQLite. GitHub Pages подходит только для статических сайтов и не запустит этот бэкенд.
